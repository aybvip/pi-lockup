# π🔒 — ما هو "قفل" عملة Pi فعليًا؟

> **مستقل وغير رسمي.** هذا المشروع غير مرتبط بـ Pi Network ولا معتمد منها. ليس نصيحة مالية.
> كل رقم هنا إمّا مقتبس من وثيقة رسمية، أو مقاس على البلوكشين العام بأمر واحد يمكنك تكراره.

## الخلاصة في ست نقاط

| # | الادّعاء | الحالة |
|---|---|---|
| 1 | القفل هو **π مقفلة زمنيًا**، وليس عملة أخرى ولا سندًا ولا IOU | ✅ مثبت من البلوكشين + الورقة البيضاء |
| 2 | قفل تطبيق التعدين **مضاعف على سرعة التعدين**، لا على رصيدك | ✅ بالصيغة الرسمية |
| 3 | هناك **قفلان مختلفان** يخلطهما الناس دائمًا | ✅ موثّق أدناه |
| 4 | قفل المحفظة يبدأ تأثيره من **جلسة التعدين القادمة**، ولا يغيّر إعدادات التطبيق للترحيل القادم | ⚠️ من واجهة التطبيق (ملاحظة، لا مواصفة) |
| 5 | شرط PiPower (‏≥ 90 % لمدة 3 سنوات) **حق مشاركة**، وليس π مجانية ولا رقمًا ثابتًا | ✅ PiRC1 §3 منقولة حرفيًا |
| 6 | القفل المؤكَّد **لا يُلغى** قبل انتهاء مدته | ✅ الورقة البيضاء |

**الجملة الواحدة:** القفل يشتري لك **سرعة تعدين أعلى** (وأحيانًا حدًّا أدنى من PiPower للمشاركة)،
ولا يغيّر أبدًا **ما هي** الـ π.

## الصيغة الرسمية

من الورقة البيضاء (ديسمبر 2021)، قسم *Token Model and Mining* → *Lockup Reward*:

```
L(B) = Lt · Lp · log10(N) · B
```

| المدة | `Lt` | | النسبة | `Lp` |
|---|---|---|---|---|
| أسبوعان | 0.1 | | 25 % | 0.25 |
| 6 أشهر | 0.5 | | 50 % | 0.5 |
| سنة | 1 | | 90 % | 0.9 |
| 3 سنوات | 2 | | 100 % | 1.0 |
| | | | 200 % | 2.0 |

`log(N)` هو اللوغاريتم **العشري** لعدد جلسات التعدين السابقة (‏≈ 3 عند 1000 جلسة).

**ثلاث نتائج يُخطئ فيها الناس:**

1. الناتج `L(B)` هو **حدّ يُضاف إلى سرعة التعدين**، وليس مبلغًا يُدفع لك. رصيدك لا يتغيّر.
2. المضاعفات **تُضرب** ولا تُجمع: 3 سنوات و100 % تعني `2 × 1 = 2`، ومع `log(N) ≈ 2.8` تصبح `≈ +560 %`.
3. `log(N)` ينمو ببطء شديد: من 100 إلى 1000 جلسة يضيف `1.0` فقط، لا عشرة أضعاف.

```bash
node examples/lockup-math.mjs --lp 100 --duration 3y --sessions 630
```

## القفلان — لا تخلط بينهما

| | **أ — قفل تطبيق التعدين (إعداد)** | **ب — قفل المحفظة ("Create Lockup")** |
|---|---|---|
| المكان | إعدادات القفل في تطبيق التعدين | محفظة Pi Browser |
| ما تختاره | **نسبة** من رصيدك القابل للتحويل + مدة | **مبلغ π** من رصيدك المتاح + مدة |
| متى يعمل | عند **الترحيل القادم** إلى Mainnet | **فورًا** |
| التعزيز يبدأ | على الرصيد المُرحَّل | **من جلسة التعدين القادمة** |
| هل يغيّر الآخر؟ | لا | **لا** — التطبيق يقول ذلك صراحةً |
| الأثر على السلسلة | الرصيد المقفل بعد الترحيل | رصيد مقفل بشرط زمني (predicate) |

الاثنان **نفس الـ π الأصلية**. الفرق في **الحالة**، لا في الأصل.

## القياس على السلسلة (2026-10-23)

بأخذ عيّنة من **2000** رصيد قابل للمطالبة (claimable balance) على Pi Mainnet:
**1708 (85.4 %)** تحمل مدة تساوي — بالثانية — إحدى المدد الرسمية الأربع:

| المدة | بالثواني | بالأيام |
|---|---:|---:|
| أسبوعان | `1 209 600` | 14 |
| 6 أشهر | `15 778 476` | 182.6213 |
| سنة | `31 556 952` | 365.2425 |
| 3 سنوات | `94 670 856` | 1095.7275 |

**السنة هنا سنة يوليانية (365.2425 يومًا)**، لا 365: ‏`365 × 86400 = 31 536 000`، أي أقصر بـ
**20 952 ثانية** من الرقم الموجود فعلًا على السلسلة. و6 أشهر = نصف سنة بالضبط، و3 سنوات = ثلاثتها.

الـ π المقفلة تبقى `"asset": "native"` — القفل **شرط زمني** على رصيد، وليس أصلًا جديدًا.

```bash
node examples/lockup-census.mjs --sample 2000
```

## شرط PiPower (نصًّا)

من PiRC1 §3:

> «Any user with an active Pi lockup of ≥90% of their mined tokens for at least 3 years at the time of a
> token launch created before February 20, 2026 automatically receives a standardized, platform-defined
> baseline PiPower … **The number for PiPower_Baseline will be calibrated.**»

- ✅ **حق مشاركة** (سقف ما يمكنك الالتزام بشرائه من رموز الإطلاق).
- ✅ القيمة **غير منشورة**؛ "will be calibrated" هي المواصفة كلها.
- ⚠️ عبارة «**created before February 20, 2026**» ملتبسة فعلًا: هل "created" تعود على **الإطلاق**
  أم على **القفل**؟ النص لا يحسم. نحن **لا نحسمها بالتخمين** — [docs/PIPOWER.md](docs/PIPOWER.md) يعرض
  القراءتين وما قد يحسمهما.
- ❌ ليست π مجانية، ولا عائدًا، ولا دليلًا على أن الآلية **مفعّلة** في Launchpad الحالي.
  اقتراح ليس تنفيذًا.

## ما لا يعنيه القفل

| الفهم الخاطئ | الواقع |
|---|---|
| «π المقفلة عملة أخرى / سند» | نفس الأصل الأصلي؛ الفرق شرط زمني فقط. |
| «قفل = staking بعائد APY» | لا تُدفع أي فائدة. تكسب **مضاعف سرعة**، والـ π نفسها لا تنمو. |
| «200 % تعني رصيدًا أكبر بمرتين» | `Lp` مضاعف على `B` (المعدل)، لا على الرصيد. |
| «ربح مضمون» | تعزيز معدل بلا أي ضمان سعر، وبلا سيولة حتى نهاية المدة. |
| «أستطيع فكّه مبكرًا» | «Lockups cannot be reversed once confirmed» — لا. |
